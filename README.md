## 📊 Featured Project

### UEFA Champions League 2024/25 Performance Analysis

End-to-end football analytics project using **KNIME and Power BI**.

The project transforms match-level UEFA Champions League data into team-level performance metrics and investigates which factors are most strongly associated with winning.

**Key findings:**

- Goal Difference per Match vs Win Rate: **r = 0.89**
- Goals per Match vs Win Rate: **r = 0.80**
- Goals Conceded per Match vs Win Rate: **r = -0.73**

The project includes:

- Data preparation and transformation in KNIME
- Team-level KPI development
- Correlation analysis
- Power BI data modelling
- DAX measures
- Interactive dashboard design
- Analytical insights and documentation
